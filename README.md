# CodePilot AI

CodePilot AI is a premium AI coding command center landing page for developers who want to move from intent to production with more confidence.

## What is included

- Responsive single-page marketing experience
- Interactive workspace demo
- Agent planning and codebase intelligence storytelling
- Mobile navigation
- Monthly and annual pricing toggle
- Smooth motion and reduced-motion support
- Standalone Vite + React setup

## Run locally

```bash
pnpm install
pnpm dev
```

The Vite server uses the `PORT` and `BASE_PATH` environment variables when they are provided by a managed environment. For local development, the default Vite port and `/` base path are suitable.
